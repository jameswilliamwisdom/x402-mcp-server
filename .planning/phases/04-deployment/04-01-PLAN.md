**Script header:**
```bash
#!/usr/bin/env bash
# site/setup-server.sh — one-time server setup for 10.0.0.2
# Run from local dev machine. Requires key-based SSH to jameswisdom@10.0.0.2.
# Some steps use `ssh -t` to allocate a TTY for sudo password prompts.
set -euo pipefail

SERVER="jameswisdom@10.0.0.2"
BREW="/usr/local/bin/brew"
```

**Step 1 — Homebrew install:**
Check if $BREW exists on server. If not, run the official Homebrew install script via SSH. Print warning that brew install on macOS Monterey builds nginx from source (15+ min). Do NOT use `ssh ... "brew ..."` for the install itself — pipe the install script directly. Use:
```bash
ssh "$SERVER" '/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"'
```
After install, verify `$BREW` now exists. If Homebrew install failed, exit 1 with a clear error.

**Step 2 — nginx install:**
Run `ssh "$SERVER" "$BREW install nginx"`. The script should print: "Installing nginx — this will BUILD FROM SOURCE on macOS Monterey. Allow 10-20 minutes. Do not interrupt."

**Step 3 — Web root creation:**
```bash
ssh -t "$SERVER" "sudo mkdir -p /private/var/www/x402-network && sudo chown jameswisdom:staff /private/var/www/x402-network"
```
Note: Use `/private/var/www/` because `/var` is a symlink to `/private/var` on macOS. Both paths work but `/private/var` is canonical. After creation, verify the directory exists with `ssh "$SERVER" "test -d /var/www/x402-network && echo OK"`.

**Step 4 — Write nginx site config:**
Use SSH heredoc to write the nginx server block directly to /tmp/x402-network.conf on the server, then sudo mv it into place:
```bash
ssh "$SERVER" "cat > /tmp/x402-network.conf" << 'NGINXCONF'
server {
    listen 80;
    server_name _;

    root /var/www/x402-network;
    index index.html;

    # SPA fallback — Astro client-side routing
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Deny all dotfile paths — /.planning/, /.git/, /.env, etc.
    location ~ /\. {
        deny all;
        return 404;
    }

    # Security headers (HTTP only — no HSTS since not TLS)
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;

    # Gzip for text assets
    gzip on;
    gzip_vary on;
    gzip_types text/plain text/css text/javascript application/javascript
               application/json image/svg+xml;
    gzip_comp_level 6;
    gzip_min_length 256;

    # Long-term immutable cache for fingerprinted Astro assets
    location /_astro/ {
        expires 1y;
        add_header Cache-Control "public, max-age=31536000, immutable";
    }

    # No-cache for HTML — always serve fresh
    location ~* \.html$ {
        add_header Cache-Control "no-cache";
    }
}
NGINXCONF

ssh -t "$SERVER" "sudo mv /tmp/x402-network.conf /usr/local/etc/nginx/servers/x402-network.conf"
```

**Step 5 — LaunchDaemon plist for port 80 autostart:**
Write the plist to /tmp on the server, then sudo mv it to /Library/LaunchDaemons/. CRITICAL: Do NOT include a `UserName` key — omitting it causes the daemon to run as root, which is required for port 80. Use the version-agnostic opt symlink path `/usr/local/opt/nginx/bin/nginx`:
```bash
ssh "$SERVER" "cat > /tmp/homebrew.mxcl.nginx.plist" << 'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
  <dict>
    <key>Label</key>
    <string>homebrew.mxcl.nginx</string>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <false/>
    <key>ProgramArguments</key>
    <array>
      <string>/usr/local/opt/nginx/bin/nginx</string>
      <string>-g</string>
      <string>daemon off;</string>
    </array>
    <key>WorkingDirectory</key>
    <string>/usr/local</string>
    <key>StandardErrorPath</key>
    <string>/usr/local/var/log/nginx/error.log</string>
    <key>StandardOutPath</key>
    <string>/usr/local/var/log/nginx/access.log</string>
  </dict>
</plist>
PLIST

ssh -t "$SERVER" "sudo mv /tmp/homebrew.mxcl.nginx.plist /Library/LaunchDaemons/ && sudo chown root:wheel /Library/LaunchDaemons/homebrew.mxcl.nginx.plist"
```

**Step 6 — Validate nginx config and start:**
```bash
ssh -t "$SERVER" "sudo /usr/local/opt/nginx/bin/nginx -t"
ssh -t "$SERVER" "sudo launchctl load -w /Library/LaunchDaemons/homebrew.mxcl.nginx.plist"
```

**Step 7 — Verify nginx is up:**
```bash
echo "==> Verifying nginx is serving on port 80..."
STATUS=$(curl -s -o /dev/null -w "%{http_code}" --max-time 10 "http://10.0.0.2/")
if [[ "$STATUS" == "200" || "$STATUS" == "404" ]]; then
    echo "PASS: nginx is responding on http://10.0.0.2 (status: $STATUS)"
else
    echo "FAIL: nginx did not respond as expected (status: $STATUS)"
    echo "Check server: ssh $SERVER 'sudo /usr/local/opt/nginx/bin/nginx -t'"
    exit 1
fi
echo ""
echo "Server setup complete. nginx is live at http://10.0.0.2"
echo "Web root: /var/www/x402-network/ (empty — run deploy.sh next)"
```

Note: 404 is acceptable here (web root is empty). We just need nginx to be responding. 200 or 404 both confirm nginx is up and routing correctly.

After writing the file, run `chmod +x site/setup-server.sh`.
