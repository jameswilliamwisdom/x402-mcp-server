**Dockerfile:**
```dockerfile
FROM mcr.microsoft.com/playwright/python:v1.44.0-jammy

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY main.py .
COPY fixture.json .

EXPOSE 8000
CMD uvicorn main:app --host 0.0.0.0 --port ${PORT:-8000}
```
Key details:
- Shell form CMD (not exec form) for `${PORT}` variable expansion
- `--host 0.0.0.0` required for Railway's IPv4 proxy
- `COPY fixture.json .` explicit — the `COPY main.py .` pattern would miss it
- No `playwright install` step needed — base image has Chromium pre-installed

**railway.toml:**
```toml
[deploy]
startCommand = "uvicorn main:app --host 0.0.0.0 --port ${PORT:-8000}"
healthcheckPath = "/health"
healthcheckTimeout = 120
restartPolicyType = "ON_FAILURE"
restartPolicyMaxRetries = 3
```
`healthcheckTimeout = 120` is critical — Playwright browser takes 10-15 seconds to initialize. Without this, Railway restarts the container before ready.

  <action>
Create `x402-scraping-api/main.py` — the complete FastAPI service in a single file (matching the existing screenshot-api pattern). This is a substantial file (~300-400 lines). Follow the architecture patterns and code examples from 05-RESEARCH.md precisely.

**Structure the file in this order:**

1. **Imports and constants**
   - Standard lib: `os`, `json`, `socket`, `ipaddress`, `asyncio`, `time`, `logging`
   - From `urllib.parse`: `urlparse`, `urljoin`
   - From `io`: `StringIO`
   - FastAPI, Pydantic, Starlette
   - `fastapi_x402`: `init_x402`, `pay`
   - `playwright.async_api`: `async_playwright`, `Browser`
   - `trafilatura`
   - `bs4`: `BeautifulSoup`
   - `pandas`
   - `slowapi`
   - Logger setup: `logging.getLogger("x402-scraping")`
   - Constants: `TOTAL_BUDGET_S = 8.0`, `MAX_RESPONSE_BYTES = 5_000_000`, `ALLOWED_SCHEMES = {"http", "https"}`

2. **SSRF validation** — `validate_url_for_ssrf(url: str) -> None`
   - Parse URL, check scheme is http/https
   - Check hostname exists
   - Try parsing hostname as IP literal first (reject if private)
   - Fall back to `socket.getaddrinfo(hostname, None)` for DNS resolution
   - Check ALL resolved addresses with `_assert_ip_public(ip)`
   - `_assert_ip_public()`: unwrap IPv4-mapped IPv6 (`ip.ipv4_mapped`), check `is_private`, `is_loopback`, `is_link_local`, `is_multicast`, `is_reserved`, `is_unspecified`
   - Raises `ValueError` on any failure
   - Copy the complete implementation from 05-RESEARCH.md "Complete SSRF Validator" section

3. **Playwright route handlers**
   - `abort_private_navigation(route)` — aborts document-type navigations to private IPs (redirect-chain SSRF). Register on CONTEXT not page.
   - `handle_route(route)` — blocks resource types: `{"image", "media", "font", "websocket"}`. Do NOT block `script` (required for SPA JS rendering). Register on CONTEXT not page.
   - IMPORTANT: Both handlers registered on context level (not page level) to avoid memory leaks

4. **Browser lifespan**
   - Global `browser: Optional[Browser] = None`
   - `@asynccontextmanager async def lifespan(app)` — launches `pw.chromium.launch(headless=True, args=["--no-sandbox", "--disable-setuid-sandbox", "--disable-dev-shm-usage", "--disable-gpu"])`
   - Register `browser.on("disconnected", on_browser_disconnect)` that sets `browser = None` and logs error
   - On shutdown, close browser if connected

5. **FastAPI app setup**
   - `app = FastAPI(lifespan=lifespan)`
   - `init_x402(app, network="base")` — added FIRST (LIFO = runs LAST)
   - `app.add_middleware(SSRFMiddleware)` — added SECOND (LIFO = runs FIRST, before payment)
   - CORS middleware if needed

6. **SSRFMiddleware class**
   - Subclass `BaseHTTPMiddleware`
   - `dispatch()`: only intercept POST to `/scrape`
   - Parse JSON body, extract `url` field, call `validate_url_for_ssrf()`
   - On `ValueError`: return `JSONResponse(status_code=400, content={"detail": f"SSRF validation failed: {e}"})`
   - On `json.JSONDecodeError` or other: pass through (let Pydantic handle)
   - Copy the implementation from 05-RESEARCH.md "SSRF Middleware" section

7. **Rate limiter setup**
   - `slowapi` limiter with `get_remote_address` key function
   - Attach to app state and error handler

8. **Pydantic models**
   - `ScrapeRequest(BaseModel)`: `url: str` (HttpUrl-constrained via Annotated), `wait_for: Optional[str] = Field(None, max_length=500)`
   - Use `BoundedHttpUrl` pattern from research: `Annotated[Url, UrlConstraints(allowed_schemes=["http", "https"], max_length=2048)]`

9. **Content extraction functions**
   - `detect_block(response, html: str) -> Optional[str]` — check HTTP 403/429/503, check first 2000 chars for "Just a moment", "cf-browser-verification", "Access denied". Returns error code string or None.
   - `extract_content(html: str, page_url: str) -> dict` — the full extraction pipeline:
     a. `trafilatura.extract(html, output_format="markdown", include_links=False, include_tables=False, url=page_url, no_fallback=False)` for main content
     b. Handle `None` return (add "no_content_extracted" warning)
     c. 5MB byte-length truncation: `len(markdown.encode("utf-8")) > MAX_RESPONSE_BYTES` → truncate bytes then decode with `errors="ignore"` → add "truncated" warning
     d. `trafilatura.extract_metadata(html, default_url=page_url)` for metadata (title, description, image, url, language). Map to response schema.
     e. `BeautifulSoup(html, "lxml")` for links array — `soup.find_all("a", href=True)`, skip `#`, `javascript:`, `mailto:`, `tel:` hrefs, resolve to absolute URLs with `urljoin()`
     f. BS4 for images array — `soup.find_all("img", src=True)`, resolve src to absolute
     g. `pandas.read_html(StringIO(html))` for tables — catch `ValueError` (no tables). Convert each DataFrame to `{headers: [...], rows: [[...], ...]}`
     h. Return dict with: markdown, links, images, tables, metadata, warnings

10. **Scrape function**
    - `async def scrape_page(url: str, wait_for: Optional[str]) -> dict`
    - Check `browser is None or not browser.is_connected()` → raise HTTPException 503
    - Create new context with Chrome desktop User-Agent (not configurable per user decision), `permissions=[]`, `service_workers="block"`
    - Register `context.route("**/*", handle_route)` BEFORE creating page (block resources before navigation)
    - Register `context.route("**/*", abort_private_navigation)` for redirect-chain SSRF
    - Create page, navigate with `page.goto(url, wait_until="domcontentloaded", timeout=goto_timeout)`
    - Use shared monotonic time budget: start at `time.monotonic()`, allocate remaining budget to each Playwright call. `goto_timeout = max(1000, int((TOTAL_BUDGET_S - elapsed) * 1000))`
    - If `wait_for`: allocate remaining budget to `page.wait_for_selector(wait_for, timeout=selector_timeout)`
    - Get `html = await page.content()`, `final_url = page.url`
    - Sanitize `final_url`: if starts with `data:` or `blob:`, fall back to input URL, add warning
    - `response.status` for status code (guard `response` being `None`)
    - ALWAYS `await context.close()` in `finally` block — never close browser

11. **Route handlers**
    - `POST /scrape` — `@app.post("/scrape")` outermost, `@pay("$0.02")` inner. Decorator order is critical.
      - Check browser connected (503 if not)
      - Check content-type hint (reject non-HTML if detectable before fetch)
      - Call `scrape_page()` → get html, final_url, status_code
      - Call `detect_block()` → if blocked, return `{success: false, error: "blocked_by_protection", detail: "..."}`
      - Call `extract_content()` → get markdown, links, images, tables, metadata, warnings
      - Add `status_code`, `content_type` (from response headers if available), `content_language`, `x_robots_tag` to metadata
      - Assemble full response: `{success: true, url: input_url, final_url, markdown, links, tables, images, metadata, warnings}`
      - Handle `asyncio.TimeoutError`: return partial extraction with `{warning: "timeout"}`
      - Handle `playwright.async_api.Error`: return appropriate error response
    - `GET /scrape/test` — rate limited at 100/hour per IP via slowapi. Load and return `fixture.json`.
    - `GET /health` — always returns 200. Body: `{status: "healthy", browser: browser is not None and browser.is_connected()}`
    - `GET /` — service info: `{service: "x402-scraping-api", price: "$0.02", test: "/scrape/test"}`

**Per-wallet rate limiting on paid endpoint:**
Set 200 requests/hour per wallet. Check `request.state.x402_payer` if the attribute exists after `fastapi-x402` payment verification. If the attribute name is wrong (library internals), fall back to IP-based limiting and add a TODO comment. This is a discretion item from CONTEXT.md.

**Error handling patterns (from CONTEXT.md locked decisions):**
- Blocked sites: return 200 with `{success: false, error: "blocked_by_protection", detail: "..."}`
- Empty pages: return partial with `{warning: "no_content_extracted"}`
- Timeouts: return whatever was extracted with `{warning: "timeout"}`
- Non-HTML: reject with clear error
- SSRF: return 400, no charge (middleware handles before payment)

**Navigation strategy:** Use `wait_until="domcontentloaded"` (not `networkidle` — officially discouraged by Playwright). Follow up to 5 redirects automatically (Playwright default).
