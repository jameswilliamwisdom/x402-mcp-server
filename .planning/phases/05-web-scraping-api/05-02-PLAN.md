**Step 1: Build the Docker image locally.**

```bash
cd x402-scraping-api && docker build -t x402-scraping-api:test .
```

If the build fails:
- Missing system deps → the base image should handle this. If not, fall back to `python:3.10-slim` + explicit `apt-get` + `playwright install chromium` (documented in 05-RESEARCH.md as fallback).
- pip install failures → check version constraints in requirements.txt, adjust as needed.
- Fix any issues in Dockerfile or requirements.txt and rebuild.

**Step 2: Run the container locally.**

```bash
docker run -d --name scrape-test -p 8000:8000 \
  -e PAY_TO_ADDRESS=0x0000000000000000000000000000000000000000 \
  -e X402_NETWORK=base-sepolia \
  x402-scraping-api:test
```

Wait for the health check to pass (up to 30 seconds for Playwright browser init):

```bash
# Poll health endpoint
for i in $(seq 1 30); do
  curl -s http://localhost:8000/health && break
  sleep 1
done
```

**Step 3: Smoke test all endpoints.**

1. **Health check:** `curl http://localhost:8000/health` — expect `{"status": "healthy", "browser": true}`
2. **Root info:** `curl http://localhost:8000/` — expect service info JSON
3. **Free test:** `curl http://localhost:8000/scrape/test` — expect full fixture JSON with all fields
4. **SSRF rejection:** `curl -X POST http://localhost:8000/scrape -H "Content-Type: application/json" -d '{"url": "http://10.0.0.1/"}'` — expect 400 with SSRF error (this fires before payment, so no X-PAYMENT header needed)

**Step 4: Fix any issues discovered.**

Common issues from 05-RESEARCH.md pitfalls:
- `sync_playwright` error → must use `async_playwright` (should already be correct from Plan 01)
- `fixture.json` not found → verify `COPY fixture.json .` in Dockerfile
- Browser crash on startup → check `--no-sandbox` and `--disable-dev-shm-usage` args
- Import errors → check requirements.txt version pinning
- SSRF middleware not firing before payment → verify init_x402 is called BEFORE add_middleware(SSRFMiddleware) in code

Update `main.py` and/or `Dockerfile` as needed. Rebuild and retest.

**Step 5: Clean up.**

```bash
docker stop scrape-test && docker rm scrape-test
```
