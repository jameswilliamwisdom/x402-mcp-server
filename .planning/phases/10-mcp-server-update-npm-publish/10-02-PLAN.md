  <action>
Run the full publish pipeline:

**1. Build:**
```bash
cd /Users/jameswisdom/projects/x402-mcp-server
npm run build
```
Runs `tsc` followed by `postbuild` shebang injection.

**2. Verify shebang:**
```bash
head -1 dist/index.js
# Must output: #!/usr/bin/env node
```
If missing, the `postbuild` script failed — investigate before proceeding.

**3. Verify the built artifact starts:**
```bash
timeout 5 node dist/index.js 2>&1 || true
```
The server reads from stdin (StdioServerTransport) so it will hang. A clean start means no errors in the first 3 seconds. If it outputs "Fatal:" or stack traces, fix before proceeding.

**4. Verify tarball contents:**
```bash
npm pack --dry-run
```
Expected: exactly 5 files — `dist/index.js`, `dist/index.d.ts`, `README.md`, `LICENSE`, `package.json`. If ANY other file appears (especially `.env`, `.planning/`, `src/`, `x402-*-api/`), STOP — the `files` whitelist may be corrupted.

**5. Verify npm auth:**
```bash
npm whoami
```
Must output: `jameswilliamwisdom`. If not authenticated, pause and instruct the user to run `npm login`.

**6. Commit dist:**
```bash
git add dist/index.js dist/index.d.ts
git commit -m "build(10-02): compile v1.1.0 dist"
```

**7. Publish:**
```bash
npm publish
```
`prepublishOnly` runs `npm run build` again (safe — idempotent). Watch for errors. If publish fails, check: version conflict (1.1.0 already exists?), auth issue, network issue.

**8. Post-publish verification:**
```bash
npm view x402-mcp-server@1.1.0
```
Confirm: version is 1.1.0, description mentions all capabilities, dist.tarball URL exists.

```bash
npx -y x402-mcp-server@1.1.0 --help 2>&1 || timeout 5 npx -y x402-mcp-server@1.1.0 2>&1 || true
```
The server starts and waits for stdin — no crash means success.

**9. Git tag:**
```bash
git tag v1.1.0
git push origin v1.1.0
```

**10. Verify tag:**
```bash
git tag -l "v1.1.0"
```
