**Step 1: Build the Docker image locally.**

```bash
cd x402-search-api && docker build -t x402-search-api:test .
```

This is the simplest Docker build in the project — `python:3.11-slim` with zero apt packages. `pip install` is the only build step. Should complete in <60 seconds.

Common build failures and fixes:
- `ERROR: Could not find a version that satisfies the requirement tavily-python>=0.5.0,<0.6.0` — if 0.5.x has been yanked from PyPI, widen to `tavily-python>=0.5.0,<0.8.0` and verify `AsyncTavilyClient` import still works
- `ModuleNotFoundError: No module named 'tavily.errors'` — in some versions `UsageLimitExceededError` may be at a different import path; check `pip show tavily-python` version and adjust import

**Step 2: Run the container locally.**

```bash
docker run -d --name search-test -p 8000:8000 \
  -e PAY_TO_ADDRESS=0x0000000000000000000000000000000000000000 \
  -e X402_NETWORK=base-sepolia \
  -e TAVILY_API_KEY=tvly-test-placeholder \
  x402-search-api:test
```

Wait for startup (should be very fast — no browser, no C libs):

```bash
for i in $(seq 1 10); do
  curl -s http://localhost:8000/health && break
  sleep 1
done
```

**Step 3: Smoke test all endpoints.**

1. **Health check:** `curl http://localhost:8000/health` — expect `{"status": "healthy", "tavily": "configured"}`
2. **Root info:** `curl http://localhost:8000/` — expect service info JSON with price "$0.01", test URL, endpoints
3. **Free test:** `curl http://localhost:8000/search/test` — expect fixture JSON with `results` array, each result having `title`, `url`, `snippet`, `score` fields
4. **Payment gate:** `curl -X POST http://localhost:8000/search -H "Content-Type: application/json" -d '{"query": "test"}'` — expect 402 Payment Required (no X-PAYMENT header, payment gate fires before route handler)
5. **Validation:** `curl -X POST http://localhost:8000/search -H "Content-Type: application/json" -d '{"query": ""}'` — expect 422 Pydantic validation error (empty query, min_length=1)

**Step 4: Fix any issues discovered.**

Common runtime issues from 07-RESEARCH.md pitfalls:
- `fixture.json not found` — verify `COPY fixture.json .` in Dockerfile
- Health returns `"tavily": "not configured"` — verify `TAVILY_API_KEY` env var is being passed to container
- `ImportError` on `tavily.errors` — check the exact import path for the installed version
- 500 on test endpoint — check `FIXTURE_PATH` calculation uses `os.path.dirname(__file__)`

Update `main.py`, `Dockerfile`, or `requirements.txt` as needed. Rebuild and retest.

**Step 5: Clean up.**

```bash
docker stop search-test && docker rm search-test
```
