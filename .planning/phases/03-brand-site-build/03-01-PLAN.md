
3. Create `site/src/components/ForceDarkTheme.astro`:
```astro
---
---
<script is:inline>
  document.documentElement.dataset.theme = 'dark';
</script>
```

The `is:inline` attribute is MANDATORY — it makes the script run synchronously before first paint, eliminating flash of light mode (FOLIOM). A bundled script would run too late.
