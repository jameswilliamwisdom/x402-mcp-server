2. Verify shebang: `head -1 dist/index.js` must show `#!/usr/bin/env node`.
3. Edit `.gitignore` — change the dist/ section from:
   ```
   # Build output
   dist/
   ```
   to:
   ```
   # Build output — dist/ intentionally committed for npx github: install
   # dist/
   ```
4. Stage and commit: `git add .gitignore dist/index.js dist/index.d.ts` then commit with message `build(02-01): commit dist for npx github: direct install`.

Why dist/ must be committed: `npx -y github:user/repo` downloads the repo tarball and runs `npm install` (production deps only). The `prepare` lifecycle hook for git dependencies is unreliable in npm (issues #3692, #8440) — TypeScript compilation fails because devDependencies are not available. Committing the compiled output is the battle-tested approach.
