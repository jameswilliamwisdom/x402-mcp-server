**VAL-01: coin parameter validation** — Apply to BOTH x402_sentiment and x402_intelligence tools.

Find (in x402_sentiment, approximately line 333):
```typescript
    coin: z
      .string()
      .describe(
        "Cryptocurrency ticker symbol (e.g., 'BTC', 'ETH', 'SOL')"
      ),
```
Replace with:
```typescript
    coin: z
      .string()
      .regex(/^[A-Z0-9]{1,10}$/i)
      .describe(
        "Cryptocurrency ticker symbol (e.g., 'BTC', 'ETH', 'SOL')"
      ),
```

Find (in x402_intelligence, approximately line 408):
```typescript
    coin: z
      .string()
      .describe(
        "Cryptocurrency ticker symbol (e.g., 'BTC', 'ETH', 'SOL')"
      ),
```
Replace with:
```typescript
    coin: z
      .string()
      .regex(/^[A-Z0-9]{1,10}$/i)
      .describe(
        "Cryptocurrency ticker symbol (e.g., 'BTC', 'ETH', 'SOL')"
      ),
```

The regex `/^[A-Z0-9]{1,10}$/i` allows only alphanumeric characters, 1-10 chars. Blocks path traversal (`../`), SQL injection (`'; DROP`), and any special characters. Case-insensitive since the code already calls `.toLowerCase()` on coin values.

**VAL-02: URL validation** — Apply to x402_screenshot (url) and x402_pdf_extract (pdf_url).

Find (in x402_screenshot, approximately line 217):
```typescript
    url: z.string().describe("URL to capture (full URL including https://)"),
```
Replace with:
```typescript
    url: z.string().url().describe("URL to capture (full URL including https://)"),
```

Find (in x402_pdf_extract, approximately line 294):
```typescript
    pdf_url: z.string().describe("URL of the PDF to extract text from"),
```
Replace with:
```typescript
    pdf_url: z.string().url().describe("URL of the PDF to extract text from"),
```

`z.string().url()` enforces well-formed URL format (RFC-compliant). Any scheme is accepted — the backend APIs handle scheme restrictions. Zod default error messages are used (no custom messages per user decision).

**IMPORTANT:** Do NOT change any other code in src/index.ts. Only modify the four Zod schema definitions listed above.
