  <name>Task 1: Harden package.json — files whitelist, scripts, engines, dependencies</name>
  <files>package.json, package-lock.json</files>
  <action>
Edit package.json to add the following fields and modifications. Apply ALL changes to the existing file — do NOT rewrite from scratch.

1. **Add `files` whitelist** (PKG-01 — HIGHEST PRIORITY, do this first):
```json
"files": ["dist", "README.md", "LICENSE"]
```
Place after `"bin"` field. This is an allowlist — only these paths plus package.json will be in the npm tarball. Overrides .gitignore for publishing, so dist/ IS included even though it is gitignored.

2. **Add `engines` field** (PKG-03):
```json
"engines": {
  "node": ">=18"
}
```
Place after `"files"` field.

3. **Add lifecycle scripts** (PKG-02, PKG-05):
Update the `"scripts"` section to:
```json
"scripts": {
  "build": "tsc",
  "postbuild": "node -e \"const fs=require('fs'),f='dist/index.js',c=fs.readFileSync(f,'utf8');if(!c.startsWith('#!/'))fs.writeFileSync(f,'#!/usr/bin/env node\\n'+c)\"",
  "prepublishOnly": "npm run build",
  "start": "node dist/index.js"
}
```
- `postbuild` runs automatically after `build` and injects `#!/usr/bin/env node` if tsc stripped it. This is a defensive safety net — tsc 5.9.3 preserves shebangs, but the guard ensures correctness regardless of future tsc behavior.
- `prepublishOnly` runs `npm run build` (which triggers postbuild) before every `npm publish`. Note: does NOT run during `npm pack`.

4. **Promote zod to direct dependency** (prevents relying on transitive dep from @modelcontextprotocol/sdk):
Run: `npm install zod@^4.0.0`
This adds zod to dependencies in package.json and updates package-lock.json.

5. **Install publint as devDependency** (PKG-06):
Run: `npm install --save-dev publint`
This adds publint to devDependencies and updates package-lock.json.

Run both npm install commands. Verify package.json now has `zod` in dependencies and `publint` in devDependencies.
