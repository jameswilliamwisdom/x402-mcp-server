**Imports and globals:**

**Lifespan (model loading at startup):**
```python
@asynccontextmanager
async def lifespan(app: FastAPI):
    global model
    model = await run_in_threadpool(
        lambda: WhisperModel(
            WHISPER_MODEL, device=WHISPER_DEVICE,
            compute_type=WHISPER_COMPUTE_TYPE,
            cpu_threads=WHISPER_CPU_THREADS, num_workers=1
        )
    )
    yield
```

**App initialization and middleware (LIFO ordering):**
1. `app = FastAPI(title="x402 Transcription API", version="1.0.0", lifespan=lifespan)`
2. `init_x402(app, network="base")` — FIRST (runs LAST in LIFO)
3. CORS middleware
4. `app.add_middleware(SSRFMiddleware)` — LAST (runs FIRST in LIFO)

**SSRFMiddleware class:**
Copy the validate_url_for_ssrf() function and SSRFMiddleware class from x402-scraping-api/main.py. CRITICAL: update the path check from `"/scrape"` to `"/transcribe"`. Include the httpx redirect SSRF re-validation hook (`_validate_redirect_ssrf`).

**Request model (Pydantic):**
```python
class TranscribeRequest(BaseModel):
    url: str                              # Audio file URL (TRANS-01)
    language: Optional[str] = None        # ISO 639-1 hint; None = auto-detect (TRANS-04)
    word_timestamps: bool = False         # Word-level timestamps (TRANS-03)
```

**download_audio_url(url: str) -> str:**
Async function using httpx.AsyncClient with streaming. Two-layer 25MB size check:
1. Check Content-Length header (fast reject)
2. Accumulate chunks via aiter_bytes(chunk_size=65536), reject if total exceeds MAX_AUDIO_BYTES
Include `event_hooks={"response": [_validate_redirect_ssrf]}` for redirect SSRF protection.
Use `tempfile.NamedTemporaryFile(delete=False, suffix=".audio")` for temp file.
On error, clean up temp file in except block.
Timeout: `httpx.Timeout(60.0, connect=10.0)` — longer than scraping API because audio files are larger.

**get_audio_duration(tmp_path: str) -> float:**
Use PyAV (bundled via faster-whisper's transitive dependency):
```python
import av
container = av.open(tmp_path)
duration = float(container.duration) / 1_000_000
container.close()
return duration
```

**transcribe_audio(tmp_path: str, body: TranscribeRequest) -> dict:**
Synchronous function called via run_in_threadpool. Serialized via _model_lock:
```python
with _model_lock:
    segments, info = model.transcribe(
        tmp_path,
        language=body.language,
        word_timestamps=body.word_timestamps,
        beam_size=1, best_of=1, temperature=0,
        vad_filter=True,
    )
    segments_list = list(segments)  # CRITICAL: forces lazy generator evaluation
```

Build response dict:
- `transcript`: joined segment text
- `language`: info.language (TRANS-02)
- `language_probability`: round(info.language_probability, 3) (TRANS-02)
- `duration_seconds`: round(info.duration, 2)

If word_timestamps is True (TRANS-03):
- `timestamps`: list of {"word", "start", "end"} dicts from segment.words

Else (default):
- `segments`: list of {"start", "end", "text"} dicts

**POST /transcribe route handler:**
```python
@app.post("/transcribe")
@pay(PRICE_PER_REQUEST)
async def transcribe(request: Request, body: TranscribeRequest):
```
Pipeline:
1. Download audio (await download_audio_url)
2. Duration check (await run_in_threadpool(get_audio_duration, tmp_path))
3. Reject if > MAX_DURATION_SECONDS with 422 and clear error: `{"error": "duration_exceeded", "detail": "Audio is {X:.1f} minutes — exceeds 10-minute limit."}`  (TRANS-05)
4. Transcribe (await run_in_threadpool(transcribe_audio, tmp_path, body))
5. Return result
6. Cleanup in finally block: os.unlink(tmp_path) if exists
