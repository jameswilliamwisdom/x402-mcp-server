**launchd/com.x402.transcription.plist:**
LaunchAgent plist for macOS process persistence. Key properties:
- Label: com.x402.transcription
- ProgramArguments: absolute path to `.venv/bin/uvicorn` in the service directory, with args `main:app --host 127.0.0.1 --port 8889 --forwarded-allow-ips=*`
- WorkingDirectory: absolute path to x402-transcription-api on home server
- KeepAlive: true (auto-restart on crash)
- RunAtLoad: true (start on login)
- ThrottleInterval: 30 (prevent rapid crash loops — RESEARCH.md P8)
- StandardOutPath: /tmp/com.x402.transcription.stdout.log
- StandardErrorPath: /tmp/com.x402.transcription.stderr.log
- EnvironmentVariables:
  - PATH: /usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin (RESEARCH.md P7 — Intel Homebrew path)
  - PAY_TO_ADDRESS: FILL_IN_AT_DEPLOY
  - CDP_API_KEY_ID: FILL_IN_AT_DEPLOY
  - CDP_API_KEY_SECRET: FILL_IN_AT_DEPLOY

Use placeholder paths: `__SERVICE_DIR__` for the service directory absolute path. The deploy script will sed-replace these.

**cloudflared/config.yml:**
Cloudflare Tunnel configuration template:
```yaml
tunnel: __TUNNEL_UUID__
credentials-file: __HOME_DIR__/.cloudflared/__TUNNEL_UUID__.json

originRequest:
  connectTimeout: 30s
  keepAliveTimeout: 90s
  tcpKeepAlive: 30s

ingress:
  - hostname: transcribe.jameswisdom.ink
    service: http://localhost:8889
  - service: http_status:404
```

Use `__TUNNEL_UUID__` and `__HOME_DIR__` placeholders. The deploy script will prompt for these.

**deploy.sh:**
Bash deployment script for the home server. Steps:
1. Check platform is macOS (`uname -s` = Darwin)
2. Check architecture (`uname -m`) and warn if not x86_64
3. Check and report physical CPU cores (`sysctl -n hw.physicalcpu`) — inform user if config.py WHISPER_CPU_THREADS needs adjustment
4. Check for ffmpeg (`which ffprobe`) — install via `brew install ffmpeg` if missing (needed by faster-whisper's av dependency)
5. Create Python venv: `python3 -m venv .venv`
6. Install dependencies: `.venv/bin/pip install -r requirements.txt`
7. Test model download: `.venv/bin/python -c "from faster_whisper import WhisperModel; m = WhisperModel('small', device='cpu', compute_type='int8', cpu_threads=4); print('Model loaded OK')"` — first run downloads ~466MB model to ~/.cache/huggingface/
8. Replace `__SERVICE_DIR__` placeholder in plist with `$(pwd)`
9. Copy plist to `~/Library/LaunchAgents/com.x402.transcription.plist`
10. Prompt user to fill in env vars (PAY_TO_ADDRESS, CDP_API_KEY_ID, CDP_API_KEY_SECRET) in the copied plist
11. Load service: `launchctl load ~/Library/LaunchAgents/com.x402.transcription.plist`
12. Wait 10 seconds, then check: `curl -s http://localhost:8889/health`
13. Print Cloudflare Tunnel setup instructions (cloudflared install, tunnel create, route dns, config copy, tunnel run)

Mark deploy.sh as executable in the commit.

**Important (from RESEARCH.md pitfalls):**
- P7: Include /usr/local/bin in PATH for Intel Homebrew ffprobe
- P8: ThrottleInterval=30 prevents crash loop unload
- P9: LaunchAgents require user login — script should warn about auto-login
- P10: After cloudflared service install, inspect plist for missing "tunnel" + "run" args

**On the home server:**

1. Copy the x402-transcription-api directory to the home server (git clone, scp, or rsync)

2. Run the deploy script:
   cd x402-transcription-api && chmod +x deploy.sh && ./deploy.sh
   (Creates venv, installs deps, downloads ~466MB model, installs plist)

3. Edit plist with real credentials:
   nano ~/Library/LaunchAgents/com.x402.transcription.plist
   Replace FILL_IN_AT_DEPLOY for: PAY_TO_ADDRESS, CDP_API_KEY_ID, CDP_API_KEY_SECRET

4. Load service: launchctl load ~/Library/LaunchAgents/com.x402.transcription.plist

5. Verify local: curl -s http://localhost:8889/health && curl -s http://localhost:8889/transcribe/test

6. Set up Cloudflare Tunnel:
   brew install cloudflared
   cloudflared tunnel login
   cloudflared tunnel create transcription-api
   cloudflared tunnel route dns transcription-api transcribe.jameswisdom.ink

7. Configure tunnel: copy cloudflared/config.yml to ~/.cloudflared/config.yml, replace __TUNNEL_UUID__ and __HOME_DIR__

8. Start tunnel: cloudflared tunnel run transcription-api

9. Verify public: curl -s https://transcribe.jameswisdom.ink/health && curl -s https://transcribe.jameswisdom.ink/transcribe/test

10. Optional — install cloudflared as service: sudo cloudflared service install
    IMPORTANT (known bug P10): inspect /Library/LaunchDaemons/com.cloudflare.cloudflared.plist — verify ProgramArguments contains "tunnel" and "run"

11. Verify auto-login enabled: System Preferences > Users and Groups > Login Options > Automatic Login
