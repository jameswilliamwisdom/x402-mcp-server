### Key Integration Points

- **APIS dict → tool handlers:** All 8 APIS entries have `baseUrl` consumed by `const base = APIS.<key>.baseUrl` in corresponding tool handlers. No hardcoded URLs.
- **x402_network_info → all backends:** `Object.entries(APIS)` auto-iterates all 8 entries, fetching `${baseUrl}/health` with 3000ms timeout.
- **Type discriminator (conversion):** MCP tool sends `type` field matching Python `Literal` discriminator — `["image", "csv", "html_pdf"]` aligned.
- **Pricing alignment:** All tool descriptions match backend `@pay()` decorator values ($0.02 scraping, $0.02 conversion, $0.01 search, $0.01 email, $0.05 transcription).
- **SSRF protection:** Phases 5, 6, 9 all implement SSRFMiddleware with consistent `validate_url_for_ssrf()` pattern.
- **Payment gating:** All 5 paid routes use `@pay()` decorator; LIFO middleware ordering ensures SSRF runs before payment.
